# ismaelz-o

Projeto desenvolvido durante as aulas de progamação, nas linguagens de programação HTML, CSS, JavaScript.
O presente projeto é uma história com varios caminhos a ser percorrido pelo usuário.
feito por Felipe Ismael e Kauan Nascimento, 3B

Nossa hitória será sobre one piece
Era uma vez um jovem pirata que encontrou um mapa antigo apontando para uma ilha desconhecida na Grand Line. Ao chegar, descobriu um baú protegido por estranhas inscrições. Enquanto pensava no que fazer, um navio da Marinha apareceu no horizonte.
